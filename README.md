# Run Planner

Run Planner is a managed Run Director module for authoring concrete room and
reward routes.

The module is being rebuilt from the locked architecture in
`docs/revamp/README.md`. This branch contains the minimal managed-module shell
and the headless Checkpoint 1 catalog foundation: complete supported F-Q room
declarations, routes, requirements, rewards, templates, batch rules, physical
exit and encounter profiles, catalog validation, capacity audits, and static
control-manifest descriptors.

The module still exposes only an unavailable-status tab. It registers no
planner editor, persistence, materialization, history, execution plan, or
runtime routing behavior until the corresponding implementation checkpoints
are complete.
